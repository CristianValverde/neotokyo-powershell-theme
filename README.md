# 🚀 NeoTokyo PowerShell Theme

A beautiful, modern PowerShell terminal setup with the NeoTokyo theme.

## ⚡ Quick Start

### Opción 1: .bat (Recomendado) ⭐

1. **Descarga** este repositorio
2. **Haz doble clic** en `install.bat`
3. **Selecciona** tu modo de instalación
4. **Espera** 2-3 minutos
5. **¡Listo!** Abre Windows Terminal 🎉

### Opción 2: .exe (Para distribución)

1. **Descarga** `install.exe` desde [Releases](https://github.com/CristianValverde/neotokyo-powershell-theme/releases)
2. **Haz doble clic** en `install.exe`
3. **Selecciona** tu modo de instalación
4. **Espera** 2-3 minutos
5. **¡Listo!** Abre Windows Terminal 🎉

## 📋 Características

- 🎨 Tema NeoTokyo personalizado
- ⚡ Instalación automatizada
- 🔤 Monofoki Nerd Font
- 🌈 Syntax highlighting
- 📁 Terminal Icons
- 🎯 Git integration
- ⏱️ Execution time tracking

## 📦 Modos de instalación

- **Theme Only**: Solo tema y colores
- **Express**: Tema + funciones básicas
- **Productivity**: Express + iconos + shortcuts avanzados
- **Power User**: Todo incluido
- **Custom**: Elige qué instalar
